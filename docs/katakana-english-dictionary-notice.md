# カタカナ英語候補の辞書データ

`Core/Sources/Core/Resources/katakana-english-jmdict.tsv` は、[JMdict](https://www.edrdg.org/jmdict/j_jmdict.html) の一般語データを、[scriptin/jmdict-simplified](https://github.com/scriptin/jmdict-simplified) の 2026-08-31 版から抽出した個人用の候補辞書です。

この辞書データはコードとは別のデータとして扱い、上流プロジェクトにはコントリビュートしません。アプリは入力時にネットワークへ接続せず、同梱したデータだけを参照します。
